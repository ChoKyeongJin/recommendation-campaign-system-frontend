제작 정보
- 최신 커밋의 별도 촬영용 서버(localhost:3001)에서 실제 브라우저 화면을 녹화했습니다.
- 차콜·스틸 배경, 버건디 강조색, 새 타이포그래피와 각진 카드 디자인을 반영했습니다.
- 영상의 타이틀·프레임·커서와 재생 페이지도 새 디자인에 맞췄습니다.
- '30대 여성 고객' 주제로 조건을 생성하고 첫 번째 초안을 실행했습니다.
- 실제 생성된 초안: '나이가 30 이상 39 이하이고 성별이 여성인 활성 고객인 고객'
- 실제 결과 24명 / 24건을 사용했습니다.
- 주제 해석, 초안 근거, 모델 선택, 호출 한도, LLM 호출·비용 등 현재 UI를 반영했습니다.
- 생성·처리 대기 구간과 화면 탐색 속도를 편집했습니다. 성능 측정 영상이 아닙니다.
- 화면 데이터와 API 응답을 대체하거나 결과를 합성하지 않았습니다.
- 브라우저 촬영 환경에만 커서 강조와 개발 도구 표시 숨김을 적용했습니다.
- 프로젝트의 애플리케이션 소스와 설정은 변경하지 않았습니다.
- 타겟 만들기 화면만 사용했습니다. 작동 방식·조건 구성·설정 화면은 제외했습니다.
- 한국어 자막은 영상에도 포함되어 있습니다. SRT는 별도 사용을 위한 파일입니다.
- 배경음악은 실제 피아노 녹음 샘플로 새로 구성한 72 BPM의 잔잔한 피아노 연주입니다.
- 타악기 없이 부드러운 화음과 여백 있는 멜로디를 사용했습니다. 내레이션은 없습니다.
- 음량 목표는 이전 조용한 버전과 같은 -29 LUFS입니다. 끝부분은 부드럽게 잦아듭니다.
- 피아노 샘플: Salamander Grand Piano V3 / Alexander Holm / CC BY 3.0.
  https://creativecommons.org/licenses/by/3.0/
  출처와 가공 내용은 audio/credits.txt(배포 ZIP에서는 credits.txt) 및 MP4 메타데이터에 포함했습니다.

편집 소스
- film.html: 타이틀, 자막, 전환 효과
- render.cjs: 타임라인, 음원 합성, MP4 렌더링
- piano-music.cjs: 실제 피아노 샘플을 사용하는 악보와 연주 렌더링
- audio/: 피아노 샘플과 저작자·라이선스 표기
- capture.cjs: 실제 화면 녹화
- capture.json: 사용한 녹화 파일과 장면 시간
- edit.json: 최종 편집 타임라인
- raw/: 사용한 원본 화면 녹화
- verify.cjs: 전체 디코딩, 포맷, faststart, 타임라인 검사
- prepare-web.cjs: 웹 배포용 영상·폰트·WebVTT 자막·버전 정보 준비
- web/dist/index.html: 반응형 웹 재생 페이지와 장면 바로가기
- web/.openai/hosting.json: Sites 배포 대상
- npm run build / pnpm build 시 public/portfolio-video/에 재생 파일을 자동 준비합니다.
- 서버 배포 후 재생 주소: http://3.39.216.91/portfolio-video/index.html
- public/portfolio-video/는 생성 파일이며 Docker standalone 이미지에도 포함됩니다.
- 촬영 시각과 전체 소스 커밋은 capture.json 및 edit.json에 기록했습니다.

이 PC에서 재렌더링
  node artifacts\portfolio-video\render.cjs
  node artifacts\portfolio-video\verify.cjs
  node artifacts\portfolio-video\prepare-web.cjs

현재 화면을 새로 촬영하려면 렌더링 전에 실행
  node artifacts\portfolio-video\capture.cjs

화면 재인코딩 없이 배경음악만 갱신
  node artifacts\portfolio-video\render.cjs --audio-only

렌더 도구는 프로젝트 의존성 대신 %TEMP%\rcs-portfolio-video-tools에 설치했습니다.
도구 폴더가 지워진 경우 PowerShell에서 다음 명령으로 다시 설치할 수 있습니다.
  npm install --prefix "$env:TEMP\rcs-portfolio-video-tools" --no-audit --no-fund playwright ffmpeg-static sharp
Chrome 기본 설치 경로를 사용합니다. 새로 촬영하려면 localhost:3000과 백엔드가 필요합니다.
다른 프런트엔드 주소는 CAPTURE_ORIGIN 환경 변수로 지정할 수 있습니다.
